# 吉伊卡哇 · 草原小日子

使用生成插画的吉伊卡哇同人跑酷游戏。选择吉伊、小八或乌萨奇，收集金币、避开蘑菇怪与荆棘，完成除草资格特训。

[GitHub Pages 在线游戏](https://wangyy992.github.io/chiiiikawa/)

## 本次重做

- 生成的水彩草原、奇美拉、蘑菇、荆棘、金币、吉他与草地平台。
- 远景不参与碰撞；危险物上方标红色 !；绿色顶面可站立，主跑道连续。

- 保留固定步长物理、二段跳、可变跳高、平台碰撞和受伤无敌。重新加入裂谷飞行区；普通气流飞行仍会受伤，吉他应援飞行 10 秒内伤害全免并能撞碎障碍。
- Canvas 仅合成 PNG 图片，界面使用 HTML/CSS，旧代码绘制的美术已移除。

## 操作

| 操作 | 效果 |
| --- | --- |
| 空格 / ↑ / W / 点击画面 | 跳跃，空中可再跳一次 |
| 长按后松开 | 控制跳跃高度 |
| 方向键 / WASD / 拖动 | 吃到吉他后的 10 秒无敌飞行 |
| P / 暂停按钮 | 暂停和继续 |
| M / 音效按钮 | 静音 |
| 手机跳跃按钮 | 跳跃 |
| 切换窗口 | 自动暂停 |

碰撞会缩短与奇美拉的距离，被追上则结束。应援飞行中可撞碎障碍并增加金币。
吉他是稀有道具，生成概率为 35%，两把之间至少相隔约 650 米，不会连续触发飞行。

## 运行与部署

直接打开 index.html 即可游玩；也可运行 python -m http.server 8000。
没有安装依赖或构建步骤。

GitHub 仓库 Settings → Pages → Source 选择 GitHub Actions，推送 main 后由现有 pages.yml 自动部署。

## 结构

- assets/：14 张实际使用的背景、裂谷、角色和物件 PNG。
- js/raster.js：素材预加载、角色信息、安全本地存储。
- js/world.js：带安全间距的连续地面关卡。
- js/game.js：物理、碰撞、收集、追击与证书。
- js/render.js：图片合成与危险标记。
- js/main.js：选角、输入、证书界面与主循环。
- js/config.js：手感参数。
- js/utils.js：数学工具与音效。
- docs/art-direction.md：素材生成说明。

## 数据

没有账号、后端、API 凭据或令牌。localStorage 只保存 chii_best（最远距离）、chii_character（所选角色）、chii_cert（最高证书）。
清理浏览器数据会重置，不跨设备同步；禁止存储时仍可游玩。
