# 小可爱除草大逃亡 · Sunny Coast Run

一个纯前端的横版跑酷小游戏：小可爱在阳光海岸一路狂奔考「除草证」，身后跟着一群讨伐怪，
路上捡硬币（工资）、躲障碍，吃到应援吉他就腾空进入 **10 秒无敌飞行**，地面断裂时则整段切成
**飞行区**，在上下交错的浮空岩柱之间穿行。

**零依赖、零构建**：HTML5 Canvas + 原生 JavaScript，直接双击 `index.html` 就能玩，
推到 GitHub 开启 Pages 就是一条可以发给别人的链接。

---

## 为什么不用 Unity

| | 网页版（本项目） | Unity WebGL |
|---|---|---|
| 包体 | ~60 KB，秒开 | 10–30 MB，首屏要转圈几秒 |
| 分发 | GitHub Pages 一条链接，手机扫码就玩 | 需要托管构建产物，移动端兼容性一般 |
| 改一个手感参数 | 改 `js/config.js`，刷新页面 | 改完要重新构建 |
| 学习/维护成本 | 只要会 JS | 引擎 + C# + 构建流水线 |

2D 跑酷需要的东西——重力积分、AABB 碰撞、无限地图生成、状态机——全部是几百行 JS 的量级。
Unity 的价值在 3D、复杂物理、粒子/动画工作流和多平台原生打包；本项目全都用不上，所以
**GitHub + 网页完全够用，而且更适合这个体量**。

## 玩法

| 操作 | 说明 |
|---|---|
| `空格` / `↑` / `W` / 点击屏幕 | 跳跃（支持二段跳，长按跳更高） |
| `方向键` / `WASD` / 按住拖拽 | **飞行状态**下的二维自由移动 |
| `P` | 暂停 / 继续 |
| `M` | 静音 |

- 撞到障碍不会立刻结束，而是被身后的讨伐怪拉近距离；距离归零就是「被讨伐」。
- 吃到 🎸 应援吉他 → 腾空 10 秒无敌，期间撞碎障碍还能换成工资。
- 掉进海里同样出局。
- 每 800m 推进一级「除草证」进度。

## 核心设计

### 1. 双形态状态机（`js/game.js`）

物理规则完全由 `p.state` 决定，两套规则互不干扰：

```
RUN                                  FLY
├─ 重力积分 vy += G * dt              ├─ 关闭重力，vx/vy 由输入加速度驱动
├─ 跳跃初速度 + 可变跳跃高度            ├─ 二维自由移动 + 阻尼漂浮
├─ 严格地面/高台碰撞（仅下落时判定）      ├─ 取消地面判定，改为全屏边界钳制
└─ 土狼时间 / 跳跃缓冲                  └─ 入场上升气流把角色托到舒适高度
```

进入 FLY 有两条路径，用 `flyReason` 区分，互相不会打架：

- `flyReason = 'item'`：吃到吉他，倒计时 `ITEM_FLY_TIME`（10 秒）、无敌、撞碎障碍；
  倒计时结束时如果人还在飞行区上空，就自动降级为 `'zone'` 继续飞，否则落回地面。
- `flyReason = 'zone'`：地图生成器排到飞行区块，角色越过断崖前 60px 被上升气流托起；
  飞出该区块回到地面区块时自动落地。

### 2. 两个区块池（`js/world.js`）

地图按「区段（span）」无限生成，两个独立的图案池：

- **GROUND 池**：灌木 / 岩石 / 高台 / 站桩讨伐怪 / 硬币弧线，区段起点保留 `LANDING_RUNWAY`
  的安全跑道，保证从飞行区落地时不会一头撞死。
- **SKY 池**：上下交错的浮空岩柱、留缝的「门」、正弦巡逻的飞怪、波浪硬币带。

区段末尾地面直接断开（渲染时只在与飞行区相邻的一侧画断崖竖线），生成器无缝切到另一个池。
相机后方的实体每帧裁剪，长时间游玩实体数量保持恒定（实测 60s / 2800m 后仅剩约 30 个活跃实体）。

### 3. 其他

- **固定步长积分**（`js/main.js`，1/120s）：掉帧或切后台回来也不会穿模。
- **追击压力**：撞一次减少领先距离，跑得干净会缓慢拉开，归零即被追上——比一撞就死更耐玩。
- **无素材**：所有角色、怪物、道具、地形都是 `js/art.js` 里用 Canvas 路径画的原创简笔造型；
  音效是 WebAudio 现场合成的方波，仓库里没有任何图片/音频文件。

## 文件结构

```
index.html        页面骨架与开始/结算界面
css/style.css     UI 样式（自适应 16:9 舞台）
js/config.js      所有手感参数（重力、跳跃、飞行、生成、追击）——调参只动这里
js/utils.js       数学工具 + WebAudio 音效
js/art.js         全部程序化绘制的造型
js/world.js       无限地图生成器（GROUND / SKY 双区块池）
js/game.js        状态机、物理、碰撞、结算
js/render.js      渲染与 HUD
js/main.js        输入、HiDPI 适配、固定步长主循环
```

## 本地运行

```bash
# 方式一：直接双击 index.html（没有模块，file:// 也能跑）
# 方式二：起个静态服务器
npx serve .
```

## 部署到 GitHub Pages

仓库设置 → Pages → Source 选 **GitHub Actions**，推到 `main` 后
`.github/workflows/pages.yml` 会自动发布，得到 `https://<用户名>.github.io/<仓库名>/`。

## 接下来可以加的东西

- 二段加速冲刺、地面滑铲（再加一个 `SLIDE` 状态即可）
- 每日种子（同一天所有人跑同一张图）+ 本地排行榜
- 更多区块图案：只要往 `fillGround` / `fillSky` 的 `pattern` 池里加一个 case
- 手机端震动反馈、BGM
